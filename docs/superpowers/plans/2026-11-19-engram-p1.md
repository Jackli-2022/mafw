# P1：learned k-WTA shadow 实现计划

**Goal:** 在冻结的 turn 数据集上训练低秩 learned k-WTA（M=4096, r=64, k=16），
与「直接 k-WTA / 12-anchor / dense」对比分离与检索指标；不过门槛就停止，不改生产。

**Spec:** `docs/research/2026-11-19-hippocampus-cortex-design-kimi.md`
**Constraints:** 只读 raw T1；离线训练；新码只进派生表；默认 off；不改 100ms 边界路径。

### Task 1: 导出冻结数据集

- `gateway/scripts/export-engram-dataset.ts`
- 500 个 ≥6 turn 的 session，每个取前 6 轮；按 session 70/15/15 切分。
- 输出 `gateway/scripts/fixtures/engram-p1/`：`vectors.f32` + `meta.json`（含 model/dims/hash/splits）。
- 不提交二进制数据；只提交脚本。

### Task 2: 基线评估

- `gateway/scripts/eval-engram-baseline.ts`
- 计算：12-anchor、直接 k-WTA、dense cosine。
- 指标：same-episode vs random AUC、hard-negative AUC、top-1 same-episode、R@10。
- hard negative：dense cosine ≥0.7 且不同 episode。
- 输出 `baseline.json`。

### Task 3: 训练 learned k-WTA

- `gateway/scripts/train-t1-engram.py`（torch）
- 模型：`a = U(Vx)+b`，`z = softplus(a)·TopK`，`x̂ = normalize(Wᵀz)`，`W=UV`。
- 损失：`rec + λ_c NCE + λ_d KD + λ_h hub`；early stop on val。
- 导出 `weights.f32` + `manifest.json`（U/V/b、metrics、hashes）。

### Task 4: 评估 learned 码

- 复用 Task 2 指标，比较 learned vs 直接 k-WTA vs dense。
- P1 门槛：分离 AUC +0.03（CI>0）、R@10 非劣 -0.01、R@1 非劣 -0.02、df_max 达标。
- 不达标 → 记录 inconclusive/stop。

### Task 5（仅通过后）: shadow 存储与推理模块

- `gateway/src/recall/t1-engram-code.ts` + 单元测试（小模型 matmul/top-k）。
- `t1_engram_codes` 派生表 + 回填脚本；**不接入 fuseT1Hits**。
