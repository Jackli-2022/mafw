# T1 Raw Replay Phase 4B Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn 4A's single-pass replay into small-step consolidation with repetition-reinforcement and raw-T1-aware reconsolidation, without rewriting raw T1 or letting mere re-encounter trigger revisions.

**Architecture:** Reflection processes episodes in bounded batches. A duplicate write that carries exact `source_trace_ids` no longer disappears: it unions provenance into the existing canonical memory and applies a small bounded energy reinforcement. The daily reconsolidation pass receives the same bounded raw-T1 evidence, so keep/rewrite is judged against originals, not only newer gists.

**Tech Stack:** TypeScript, better-sqlite3, Jest.

**Spec:** `docs/superpowers/specs/2026-11-10-t1-experience-knowledge-skill-design.md` §6.2 / §7.

## Global Constraints

- Raw T1 stays immutable; replay/reinforcement only reads raw rows and updates derived state.
- Reinforcement is bounded: duplicate skip adds at most `+0.02` energy (cap 1.0) and only when the incoming write carries `source_trace_ids`.
- Reconsolidation still requires newer related material; raw T1 alone never triggers a rewrite.
- `keep` stays no-op; only the existing prediction-error gate (`update`) may rewrite.
- Batch/replay failures are fail-open and must not lose unreflected episodes.
- No new model/provider; reuse the existing reflection/reconsolidation workers and daily budget gate.

## Review Focus

- A duplicate write without provenance must remain a pure no-op (legacy behavior unchanged).
- Repeated duplicate writes must not push energy past 1.0.
- A failed batch must not mark its episodes reflected.
- Raw replay must not turn `keep` into `rewrite`; the verdict gate is untouched.
- Reconsolidation with no newer related memories must skip without spending a worker call.

### Task 2: Duplicate Reinforcement with Provenance Union

**Files:**
- Modify: `gateway/src/memory/route-write.ts`
- Test: `gateway/tests/unit/memory/route-write.test.ts`

**Interfaces:**
- Skip outcome gains optional `reinforced?: boolean`.
- On `skip`, when `unit.source_trace_ids` is non-empty:
  - read target; union incoming+target ids (`unionSourceTraceIds`);
  - write `{ ...target, source_trace_ids: union, energy: min(1, target.energy + 0.02), updated_at }`;
  - return `{ action:'skip', id, targetId, reinforced:true }`.
- No provenance or missing target → unchanged skip (no write).
