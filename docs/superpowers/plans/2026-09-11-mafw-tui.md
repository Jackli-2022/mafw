# MAFW TUI 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 `packages/tui`（pi-tui + @mafw/sdk 纯客户端终端 UI），四 tab（Chat/Goals/Memory/Triage），`mafw tui` 子命令启动。

**Architecture:** TUI 是 gateway 的纯 HTTP/SSE 客户端（不 import gateway 内部类）。分层 `ui/`（pi-tui 组件）→ `store/`（状态机，纯 TS）→ `@mafw/sdk`。渲染器 `TuiAltScreen` + `setLayoutRoot(VStack)`：固定 TabStrip/StatusBar + 弹性内容区；弹窗走 `tui.showOverlay()`。

**Tech Stack:** TypeScript（ESM, nodenext）· `@earendil-works/pi-tui@^0.84.1` · `@mafw/sdk`（workspace）· chalk@5 · node:test 测试

**Spec:** `docs/superpowers/specs/2026-09-11-mafw-tui-design.md`

## Global Constraints

- Node engines：`>=22.19.0`（pi-tui 要求；该版本起全局 `EventSource` 可用）
- pi-tui 是 ESM-only（`"type": "module"`）——packages/tui 必须 `"type": "module"`
- 只连 loopback gateway；TUI 不 spawn/管理 gateway 进程
- 数据出口只有 `@mafw/sdk`；store 层禁止 import pi-tui
- 自定义组件 `render(width)` 每行不得超宽，统一 `truncateToWidth()` 兜底
- 嵌 Editor/Input 的容器必须实现 `Focusable` 传播 `focused`（中文 IME 候选窗定位）
- Tool 调用 running 期间只渲染一行状态摘要，terminal state 才填结果（mem_yw2lqt 教训）
- 每个新文件创建后立即 git add；每个 Task 结束 commit
- Windows 开发机：bash 工具是 PowerShell 5.1，无 `&&`，用 `cmd1; if ($?) { cmd2 }`

## 关键事实（executor 必读，已验证）

- pi-tui 导出名（`dist/index.d.ts`）：`TuiAltScreen, ProcessTerminal, isViewportTUI, Container, Box, Text, TruncatedText, Input, Editor, Markdown, Loader, CancellableLoader, SelectList, SettingsList, Spacer, ScrollView, VStack, HStack, matchesKey, Key, CombinedAutocompleteProvider, visibleWidth, truncateToWidth, wrapTextWithAnsi, CURSOR_MARKER, type Component, type Focusable, type TUI, type ViewportTUI, type OverlayHandle`。**无 VirtualTerminal 导出**——UI 测试直接调组件 `render(width)`/`handleInput(data)` 断言，不需要真终端。
- SDK 命名空间（`packages/gateway-sdk/src/client.ts`）：`client.session / .project / .event / .goals / .memory / .approvals / .triage / .questions / .permissions / .manager / .mafwCommands`。构造：`new MafwClient('http://localhost:3000')` 或 `new MafwClient({ baseUrl })`。
- `client.event.subscribeToSession(sessionID)` → `{ on(event, cb) }`，事件 `message.part.updated` / `session.idle` / `permission.asked`；内部 `SSEConnection` 有 `connected` getter 和测试用 `emit()`。
- **`TriageItem` 类型缺 `id` 字段**（SDK 类型缺口），wire 里实际有（desktop 用 `t.id`）——统一用 `type TriageRow = TriageItem & { id: string }`。
- `ManagerSessionInfo = { projectDir, sessionId, createdAt? }`；`client.manager.session(projectDir?)` 可能返回 `null`。
- `client.session.messages({ path:{id}, query:{limit, before} })` → `{ data: SessionMessagePart[], nextCursor: string|null }`。
- npm publish 注意事项：root `package.json` 的 `files` 不含 `packages/`；pi-tui/chalk 必须进 **root dependencies** 才能在全局安装后可用（workspaces 开发期 hoist 到 root node_modules，TUI 从 packages/tui 向上解析命中同一副本）。

```ts
/** 探测 gateway /health，按候选顺序返回第一个可用 baseUrl；全失败返回 null。 */
export async function probeGateway(
  fetchFn: typeof fetch = fetch,
  candidates: string[] = defaultCandidates(),
  timeoutMs = 2000,
): Promise<string | null> {
  for (const base of candidates) {
    try {
      const res = await fetchFn(`${base}/health`, { signal: AbortSignal.timeout(timeoutMs) })
      if (res.ok) return base
    } catch { /* try next */ }
  }
  return null
}

export function defaultCandidates(): string[] {
  const port = process.env.MAFW_SERVER_API_PORT || process.env.MAFW_GATEWAY_PORT
  const urls: string[] = []
  if (port) urls.push(`http://localhost:${port}`)
  urls.push('http://localhost:3000')
  return [...new Set(urls)]
}
```

export const TABS: { id: TabId; label: string }[] = [
  { id: 'chat', label: 'Chat' },
  { id: 'goals', label: 'Goals' },
  { id: 'memory', label: 'Memory' },
  { id: 'triage', label: 'Triage' },

  private active: TabId = 'chat'
  private connected = false
  setActive(id: TabId) { this.active = id }
  setConnected(ok: boolean) { this.connected = ok }
  render(width: number): string[] {
    const tabs = TABS.map((t, i) => {
      const label = `${i + 1}:${t.label}`
      return t.id === this.active ? theme.active(label) : theme.inactive(label)
    }).join(theme.dim('│'))
    const conn = this.connected ? theme.ok('●') : theme.err('●')
    return [truncateToWidth(`${tabs} ${theme.dim('gateway:')}${conn}`, width)]
  }
}

- [ ] **Step 3: 实现 `packages/tui/src/store/connection.ts`**

```ts
export type ConnState = 'ok' | 'reconnecting' | 'down'

export interface ConnectionDeps {
  sessionID: string
  subscribe: (sid: string) => Promise<{ on(e: string, cb: (d: any) => void): () => void }>
  isConnected: () => boolean
  onEvent: (type: string, data: any) => void
  onState: (s: ConnState) => void
  schedule?: (fn: () => void, ms: number) => void
}

const BACKOFF = [1000, 2000, 5000, 15000]
const EVENTS = ['message.part.updated', 'session.idle', 'session.error', 'permission.asked', 'question.asked']

export class ConnectionStore {
  private backoffIdx = 0
  private stopped = false
  private unsubs: (() => void)[] = []
  private schedule: (fn: () => void, ms: number) => void

  constructor(private deps: ConnectionDeps) {
    this.schedule = deps.schedule ?? ((fn, ms) => { setTimeout(fn, ms) })
  }

  start(): void {
    void this.subscribe()
    this.schedule(() => this.healthTick(), 1000)
  }

  stop(): void {
    this.stopped = true
    for (const u of this.unsubs) u()
    this.unsubs = []
  }

  private async subscribe(): Promise<void> {
    if (this.stopped) return
    try {
      const sub = await this.deps.subscribe(this.deps.sessionID)
      for (const e of EVENTS) this.unsubs.push(sub.on(e, (d) => this.deps.onEvent(e, d)))
      this.unsubs.push(sub.on('*', (d) => {
        if (!EVENTS.includes(d?.type)) this.deps.onEvent(d?.type ?? 'message', d)
      }))
    } catch {
      this.deps.onState('down')
    }
  }

  private healthTick(): void {
    if (this.stopped) return
    if (this.deps.isConnected()) {
      if (this.backoffIdx !== 0) { this.backoffIdx = 0 }
      this.deps.onState('ok')
      this.schedule(() => this.healthTick(), 1000)
      return
    }
    this.deps.onState('reconnecting')
    const delay = BACKOFF[Math.min(this.backoffIdx, BACKOFF.length - 1)]
    this.backoffIdx++
    this.schedule(() => { void this.resubscribe() }, delay)
  }

  private async resubscribe(): Promise<void> {
    if (this.stopped) return
    for (const u of this.unsubs) u()
    this.unsubs = []
    await this.subscribe()
    this.schedule(() => this.healthTick(), 1000)
  }
}
```

注意：真实 SDK 的 `SSEConnection` 内部 `EventSource.onerror` 会自动重连（浏览器语义），但 Node 原生 EventSource 行为一致（自动 retry）。本 store 的 resubscribe 是**兜底**（长时间断开时 SDK 层可能放弃），健康 tick 读 `client` 暴露的 connected 状态。给 `MafwClient` 增加 connected 暴露属于 SDK 改动——见 Task 11 收尾里的 SDK 小改（`client.event.connected(): boolean` 委托 SSEConnection）。本 Task 的 `isConnected` 注入点不受影响。

```ts
export interface ChatPart {
  id: string
  type: string
  text: string
  state?: 'running' | 'completed' | 'error'
  toolName?: string
}
export interface ChatTurn {
  messageID: string
  role: 'user' | 'assistant'
  parts: ChatPart[]
  done: boolean
}

export interface SessionApi {
  messages(p: { path: { id: string }; query?: { limit?: number; before?: string } }): Promise<{ data: any[]; nextCursor: string | null }>
  promptAsync(p: { path: { id: string }; body: { parts: Record<string, unknown>[] } }): Promise<void>
  abort(p: { path: { id: string } }): Promise<void>
}

export class ChatStore {
  readonly turns: ChatTurn[] = []
  streaming = false
  private cursor: string | null = null
  private byMessage = new Map<string, ChatTurn>()

  constructor(private deps: { session: SessionApi; sessionID: string; onChange: () => void }) {}

  async loadHistory(limit = 50): Promise<void> {
    const res = await this.deps.session.messages({ path: { id: this.deps.sessionID }, query: { limit } })
    this.cursor = res.nextCursor
    this.turns.length = 0
    this.byMessage.clear()
    for (const p of res.data) this.upsertHistoryPart(p)
    this.deps.onChange()
  }

  async loadOlder(): Promise<number> {
    if (!this.cursor) return 0
    const res = await this.deps.session.messages({ path: { id: this.deps.sessionID }, query: { limit: 50, before: this.cursor } })
    this.cursor = res.nextCursor
    const older: ChatTurn[] = []
    const map = new Map<string, ChatTurn>()
    for (const p of res.data) {
      let t = map.get(p.messageID)
      if (!t) { t = { messageID: p.messageID, role: partRole(p), parts: [], done: true }; map.set(p.messageID, t); older.push(t) }
      t.parts.push(historyPart(p))
    }
    this.turns.unshift(...older)
    this.deps.onChange()
    return older.length
  }

  async send(text: string): Promise<void> {
    const mid = `local-${Date.now()}`
    const turn: ChatTurn = { messageID: mid, role: 'user', parts: [{ id: `${mid}-p`, type: 'text', text }], done: true }
    this.turns.push(turn)
    this.streaming = true
    this.deps.onChange()
    await this.deps.session.promptAsync({ path: { id: this.deps.sessionID }, body: { parts: [{ type: 'text', text }] } })
  }

  async abort(): Promise<void> {
    await this.deps.session.abort({ path: { id: this.deps.sessionID } })
    this.streaming = false
    this.deps.onChange()
  }

  applyEvent(type: string, data: any): void {
    if (type === 'message.part.updated') {
      const part = data?.properties?.part
      if (!part || part.sessionID && part.sessionID !== this.deps.sessionID) return
      this.applyPart(part)
      this.deps.onChange()
    } else if (type === 'session.idle') {
      this.streaming = false
      const last = this.turns.at(-1)
      if (last && last.role === 'assistant') last.done = true
      this.deps.onChange()
    }
  }

  private applyPart(part: any): void {
    let turn = this.byMessage.get(part.messageID)
    if (!turn) {
      turn = { messageID: part.messageID, role: 'assistant', parts: [], done: false }
      this.byMessage.set(part.messageID, turn)
      this.turns.push(turn)
    }
    const idx = turn.parts.findIndex(p => p.id === part.id)
    const cp = livePart(part)
    if (idx >= 0) turn.parts[idx] = cp   // 快照替换，非拼接
    else turn.parts.push(cp)
  }

  private upsertHistoryPart(p: any): void {
    let t = this.byMessage.get(p.messageID)
    if (!t) {
      t = { messageID: p.messageID, role: partRole(p), parts: [], done: true }
      this.byMessage.set(p.messageID, t)
      this.turns.push(t)
    }
    t.parts.push(historyPart(p))
  }
}

function partRole(p: any): 'user' | 'assistant' {
  return p.role === 'user' ? 'user' : 'assistant'  // wire 字段以实现时确认结果为准
}
function historyPart(p: any): ChatPart {
  return { id: p.id, type: p.type, text: p.text ?? '', state: 'completed', toolName: p.tool }
}
function livePart(part: any): ChatPart {
  if (part.type === 'tool') {
    const st = part.state?.status === 'completed' ? 'completed' : part.state?.status === 'error' ? 'error' : 'running'
    const cmd = part.state?.input?.command ?? part.state?.input?.description ?? ''
    const out = part.state?.status === 'completed' ? String(part.state.output ?? '') : ''
    return { id: part.id, type: 'tool', toolName: part.tool, state: st, text: out ? `${cmd}\n${out}` : String(cmd) }
  }
  return { id: part.id, type: part.type ?? 'text', text: part.text ?? '' }
}

  active: TabId = 'chat'
  helpVisible = false
  /** 输入焦点在 Editor/Input 时，字符键（q/?/数字）归编辑器；此标志由 app.ts 按 tab/焦点状态注入 */
  editing = false

  toggleHelp(): void { this.helpVisible = !this.helpVisible }

    if (matchesKey(data, Key.ctrl('c'))) return 'quit'
    if (this.editing) return null  // 编辑态把按键留给输入组件
    if (matchesKey(data, 'q')) return 'quit'
    if (data === '?') { this.toggleHelp(); return null }
    const idx = ['1', '2', '3', '4'].indexOf(data)
    if (idx >= 0) this.switchTab(TABS[idx].id)
    return null
  }

/** 把一个 ChatTurn 渲染为 ANSI 行（全部 ≤ width）。 */
export function turnToLines(turn: ChatTurn, width: number): string[] {
  const lines: string[] = []
  for (const part of turn.parts) {
    if (part.type === 'tool') {
      const icon = part.state === 'completed' ? theme.ok('✓') : part.state === 'error' ? theme.err('✗') : theme.warn('…')
      const firstLine = part.text.split('\n')[0]
      lines.push(truncateToWidth(theme.dim('▸ ') + theme.accent(part.toolName ?? 'tool') + ` ${icon} ` + theme.dim(firstLine), width))
      if (part.state !== 'running') {
        for (const l of part.text.split('\n').slice(1)) {
          for (const w of wrapTextWithAnsi(theme.dim(l), width - 2)) lines.push('  ' + truncateToWidth(w, width - 2))
        }
      }
    } else if (part.type === 'reasoning') {
      for (const l of part.text.split('\n')) {
        for (const w of wrapTextWithAnsi(l, width - 4)) lines.push(truncateToWidth(theme.dim('  ⠿ ' + w), width))
      }
    } else {
      const prefix = turn.role === 'user' ? theme.accent('> ') : '  '
      const body = part.text.split('\n').flatMap(l => wrapTextWithAnsi(l, width - 4))
      for (const w of body) lines.push(truncateToWidth(prefix + w, width))
    }
  }
  if (turn.role === 'assistant' && !turn.done) lines.push(theme.dim('  …'))
  return lines
}

  constructor(private produce: (width: number) => string[]) {}
  invalidate() { this.cachedWidth = undefined; this.cached = undefined }
  render(width: number): string[] {
    if (this.cached && this.cachedWidth === width) return this.cached
    this.cached = this.produce(width)

    this.editor.onSubmit = (text) => { void this.submit(text) }
    this.addChild(this.transcript)
    this.addChild(this.editor)
    deps.store.loadHistory().then(() => this.refreshTranscript()).catch(() => {})
  }

  async handleScrollTop(): Promise<void> {
    const n = await this.deps.store.loadOlder()
    if (n > 0) this.refreshTranscript()
  }

  private async submit(text: string): Promise<void> {
    const slash = parseSlash(text.trim())
    if (slash) {
      const reply = await this.deps.onSlash(slash.cmd, slash.args)
      if (reply) this.transcript.addChild(new Text(theme.dim(reply), 1, 0))
      this.deps.tui.requestRender()
      return
    }
    await this.deps.store.send(text)   // onChange → refreshTranscript 由 app 订阅
  }

  /** store.onChange 回调：增量渲染新 turn，重绘最后一个未完成 turn。 */
  refreshTranscript(): void {
    const turns = this.deps.store.turns
    while (this.renderedTurns < turns.length) {
      const t = turns[this.renderedTurns]
      this.transcript.addChild(new Lines((w) => turnToLines(t, w)))
      this.renderedTurns++
    }
    this.deps.tui.requestRender()
  }
}
```

（注：最后一个流式 turn 的更新依赖 `Lines.invalidate()` + re-render；`refreshTranscript` 里对已渲染的最后一个 `!done` turn 调其 Lines 实例的 invalidate——实现时保存 `lastLiveLines` 引用。`defaultEditorTheme` 若 pi-tui 未导出则构造 `{ borderColor: theme.border, selectList: {...} }`，以 `dist/components/editor.d.ts` 实际类型为准。）

    { value: 'once', label: '允许一次', description: 'just this time' },

    selectedText: (t) => theme.accent(t),
    description: (t) => theme.dim(t),
    scrollInfo: (t) => theme.dim(t),
    noMatch: (t) => theme.dim(t),
  })

  box.addChild(new Text(theme.warn('权限请求  ') + permissionSummary(req), 1, 1))
  box.addChild(list)

  const done = () => handle.hide()
  list.onSelect = (item) => { void reply(item.value as 'once' | 'always' | 'reject').finally(done) }

}

```ts
// goals-store.ts
import type { Goal, QuestionRequest } from '@mafw/sdk'

export type GoalRow = Goal & { pendingQuestion?: QuestionRequest }

export class GoalsStore {
  readonly rows: GoalRow[] = []
  private stopped = false
  private schedule: (fn: () => void, ms: number) => () => void

  constructor(private deps: {
    goals: { list(): Promise<Goal[]> }
    questions: { list(): Promise<QuestionRequest[]> }
    onChange: () => void
    schedule?: (fn: () => void, ms: number) => () => void
  }) {
    this.schedule = deps.schedule ?? ((fn, ms) => { const t = setInterval(fn, ms); return () => clearInterval(t) })
  }

  start(): void {
    void this.poll()
    this.schedule(() => { if (!this.stopped) void this.poll() }, 10_000)
  }
  stop(): void { this.stopped = true }

  async poll(): Promise<void> {
    try {
      const [goals, questions] = await Promise.all([this.deps.goals.list(), this.deps.questions.list()])
      this.rows.length = 0
      const rows: GoalRow[] = goals.map(g => ({ ...g }))
      for (const r of rows) {
        r.pendingQuestion = questions.find(q => (q as any).goalId === r.goalId)
      }
      const alive = (g: GoalRow) => g.pendingQuestion || !['DONE', 'CANCELLED', 'FAILED', 'COMPLETED'].includes(g.phase) ? 0 : 1
      rows.sort((a, b) => alive(a) - alive(b))
      this.rows.push(...rows)
      this.deps.onChange()
    } catch { /* 轮询失败保留旧数据 */ }
  }
}
```
