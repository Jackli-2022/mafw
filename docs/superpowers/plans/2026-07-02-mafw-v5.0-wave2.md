# MAFW v5.0 Wave 2 — Core Infrastructure Upgrade

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan phase-by-phase. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the MAFW v4.1→v5.0 codebase with error handling, privacy filter, hook manager, SQLite storage, memory compression pipeline, pre-compact protection, and Loop/Wave state machine.

**Architecture:** Keep existing plugin surface and Gateway scheduler. Layer new modules on top. All modules are independently testable.

**Tech Stack:** TypeScript, Node.js >=18, `better-sqlite3` (new), Jest for tests.

## Global Constraints

- All state writes must be atomic (tmp file + rename).
- Gateway must not contain business logic.
- All modules must have >=80% coverage or be added to DEGRADED.md.
- Every feature must have boundary tests.
