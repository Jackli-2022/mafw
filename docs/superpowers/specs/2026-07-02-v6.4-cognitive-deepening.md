# MAFW v6.4 Cognitive Deepening Architecture Design

> **Goal**: Introduce four cognitive mechanisms to make memory actively grow — deepen, connect, crystallize.

## Architecture Overview

```
v6.3 (Harmonic Memory)
  │  Static memory warehouse: unified storage, tier-agnostic search, cross-tier merge
  │  Limitation: passive, flat forgetting, no connections between memories
  ▼
v6.4 (Cognitive Deepening)
  │  P0: Salience perception (important errors decay 3x slower)
  │  P1: Association network (search auto-links co-retrieved memories)
  │  P2: Spaced repetition scheduler (active review scheduling)
  │  P3: Abstraction distillation (narratives → facts, procedures → axioms)
```

### Key Principles

- **Zero LLM dependency**: All engines operate on pure rules
- **Zero new storage backend**: JSON files only (cognitive graph is a single JSON file)
- **Full backward compatibility**: v6.3 units work without modification (new fields are optional)
- **Incremental adoption**: Each P can be implemented independently

### Salience Calculation

```typescript
export function calculateSalience(text: string): number {
  const HIGH: RegExp[] = [/error|crash|fail|丢失|数据损坏|宕机|critical|emergency|严重/i];
  const LOW: RegExp[] = [/info|success|完成|正常|debug|trace|verbose/i];
  if (HIGH.some(p => p.test(text))) return 1.5;
  if (LOW.some(p => p.test(text))) return 0.5;
  return 1.0;
}
```

### Energy Decay Formula

```
effectiveDecay = BASE_DECAY * (1 / salience)
BASE_DECAY = 0.01
salience=1.5 → 0.0067/day (3x slower)
salience=0.5 → 0.02/day (2x faster)
salience=1.0 → 0.01/day (unchanged)
```

### CognitiveGraph Structure

```json
{
  "version": 1,
  "updated_at": "2026-07-05T10:00:00Z",
  "edges": [
    {"source": "mem_001", "target": "mem_002", "weight": 12},
    {"source": "mem_001", "target": "mem_005", "weight": 8}
  ]
}
```

### Association Flow

```
Search returns N results (N > 1)
  → For each pair (i, j): CognitiveGraphManager.addConnection(id_i, id_j)
  → Weight += 1 for each co-occurrence
  → Update top_associations on each matching entry (top 2 by weight)
  → Return results with preloaded associations
```

### Connection Write

```typescript
addConnection(idA: string, idB: string): void {
  // Normalize: sort ids to avoid duplicates
  const [src, tgt] = [idA, idB].sort();
  const existing = this.graph.edges.find(e => e.source === src && e.target === tgt);
  if (existing) {
    existing.weight++;
  } else {
    this.graph.edges.push({ source: src, target: tgt, weight: 1 });
  }
  this.save();
}
```

### Association Pre-fetch

```typescript
getTopAssociations(id: string, topK: number = 2): string[] {
  return this.graph.edges
    .filter(e => e.source === id || e.target === id)
    .sort((a, b) => b.weight - a.weight)
    .slice(0, topK)
    .map(e => e.source === id ? e.target : e.source);
}
```

### Review Interval Formula

```
interval(days) = 1 * 2^reviewCount
reviewCount=0 → 1 day
reviewCount=1 → 2 days
reviewCount=2 → 4 days
reviewCount=3 → 8 days
reviewCount=4 → 16 days
```

### Scheduler

```typescript
export class ReviewScheduler {
  private interval: NodeJS.Timeout | null = null;

  start(periodMs: number = 3600000): void {
    this.interval = setInterval(() => this.tick(), periodMs);
  }

  stop(): void { if (this.interval) clearInterval(this.interval); }

  private tick(): void {
    const now = Date.now();
    const entries = this.indexManager.getIndex().entries;
    const tasks: Array<{ id: string; abstraction: string; overdue: number }> = [];

    for (const e of entries) {
      if (e.energy < 0.5) continue;
      const lastReview = e.last_reviewed
        ? new Date(e.last_reviewed).getTime()
        : this.getCreatedTime(e.id);
      const daysSince = (now - lastReview) / 86400000;
      const needed = 1 * Math.pow(2, e.review_count || 0);
      if (daysSince >= needed) {
        tasks.push({ id: e.id, abstraction: e.primary_abstraction, overdue: daysSince - needed });
      }
    }

    if (tasks.length > 0) {
      tasks.sort((a, b) => b.overdue - a.overdue);
      const top = tasks.slice(0, 3);
      // Write review queue
      const queuePath = path.join(this.baseDir, 'memory', '.review_queue.json');
      fs.writeFileSync(queuePath, JSON.stringify({
        generated_at: new Date().toISOString(),
        tasks: top
      }, null, 2), 'utf-8');
    }
  }
}
```

### Rule 1: T2 Episodic → T3 Semantic

Trigger: ≥3 T2 units with similar `primary_abstraction` (same first 3 words after sorting)

```
Input:
  T2: "fixed JWT refresh bug" (episodic, energy=0.7)
  T2: "resolved JWT timeout issue" (episodic, energy=0.6)
  T2: "patched JWT auth deadlock" (episodic, energy=0.8)

Output:
  T3: "JWT auth: refresh bug + timeout + deadlock" (semantic, abstraction_level=2)
  → merged_from: ["mem_t2_1", "mem_t2_2", "mem_t2_3"]
  → Old T2 units: energy → 0.4 (locked)
```

### Rule 2: T4 Procedural → L5 Global

Trigger: Same goal_id has ≥5 T4 units with successRate > 0.9

```
Output:
  L5 heuristic written to l5/heuristics.json
  abstraction_level=3
  memory_type='global'
```

### Distillation Flow


## Decision Log

| # | Decision | Rationale |
|---|---|---|
| 1 | P0 before P1 before P2 before P3 | Each builds on the previous (fields, then connections, then scheduling, then distillation) |
| 2 | Salience regex patterns are case-insensitive | Match both `Error` and `error` |
| 3 | Decay formula: `0.01 * (1/salience)` | Matches doc spec exactly |
| 4 | Cognitive graph in separate file | Avoid bloating harmonic index |
| 5 | Review scheduler runs hourly | Balance between responsiveness and CPU usage |
| 6 | Distillation threshold ≥3 for T2→T3 | Matches doc spec |
| 7 | Distillation threshold ≥5 for T4→L5 | Matches doc spec |
