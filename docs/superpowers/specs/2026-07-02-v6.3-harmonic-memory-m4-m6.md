# MAFW v6.3 Harmonic Memory M4-M6 Design

> **Goal**: Complete the Harmonic Memory system — harmonic unit compression (M4), MinHash cross-tier merging (M5), and end-to-end integration tests (M6).

## Architecture Overview

```
T1 Raw Observations
    │
    ▼
M4: HybridCompressor.compress()
    │  Outputs HarmonicUnit (instead of CompressedMemory)
    │  Writes to tier2/tier3/tier4 JSON files
    │  Updates HarmonicIndexManager
    ▼
HarmonicUnit stored in tier file + index entry added
    │
    ▼ (after write)
M5: MinHashMerger.checkAndMerge()
    │  Generates MinHash signatures for primary_abstraction
    │  Compares against all existing entries in index
    │  If Jaccard > 0.6 → merge
    ▼
Merged unit: combined abstraction, consolidated anchors, energy+0.15
```

### Tier Mapping Logic

```typescript
function detectMemoryType(observations: any[]): 'episodic' | 'semantic' | 'procedural' {
  const allContent = observations.map(o => o.content || '').join(' ');
  const isFileEdit = observations.every(o => o.type === 'file_edit' || (o.content && o.content.includes('File modified')));
  if (isFileEdit) return 'procedural';
  const hasPlan = /plan|wave|task|goal/i.test(allContent);
  if (hasPlan) return 'episodic';
  return 'semantic';  // default for rule/pattern/observation content
}
```

## M5: MinHash Cross-Tier Merger

### Algorithm

MinHash generates a fixed-size signature from a set of shingles (n-grams). Two units' signatures are compared via Jaccard approximation.

```
For each unit:
1. Extract shingles: 3-grams of lowercase primary_abstraction
2. Generate 128 hash signatures using 4 random hash functions
3. For each hash function, take minimum hash value → signature vector (size=4)

Compare two units:
  Jaccard ≈ (number of matching signature positions) / signature_length
  If > 0.6 → merge
```

### Implementation

```typescript
export class MinHashMerger {
  private signatureSize: number = 4;
  private threshold: number = 0.6;

  generateSignature(text: string): number[] {
    const shingles = this.extractShingles(text);
    const sig = new Array(this.signatureSize).fill(Infinity);
    for (const shingle of shingles) {
      for (let i = 0; i < this.signatureSize; i++) {
        const hash = this.hashFunction(shingle, i);
        if (hash < sig[i]) sig[i] = hash;
      }
    }
    return sig;
  }

  similarity(sigA: number[], sigB: number[]): number {
    let matches = 0;
    for (let i = 0; i < sigA.length; i++) {
      if (sigA[i] === sigB[i]) matches++;
    }
    return matches / sigA.length;
  }

  async merge(
    unit: HarmonicUnit,
    tier: string,
    indexManager: HarmonicIndexManager,
    baseDir: string
  ): Promise<HarmonicUnit> {
    const allEntries = indexManager.getIndex().entries;
    const newSig = this.generateSignature(unit.primary_abstraction);

    for (const entry of allEntries) {
      if (entry.id === unit.id) continue;
      const existingSig = this.generateSignature(entry.primary_abstraction);
      if (this.similarity(newSig, existingSig) > this.threshold) {
        // Load existing unit
        const existingUnit = this.loadUnit(baseDir, entry.tier, entry.id);
        if (!existingUnit) continue;

        // Merge
        unit.primary_abstraction = unit.primary_abstraction + ' + ' + existingUnit.primary_abstraction;
        unit.cue_anchors = [...new Set([...unit.cue_anchors, ...existingUnit.cue_anchors])];
        unit.memory_value = unit.memory_value + '\n---\n' + existingUnit.memory_value;
        unit.energy = Math.min(1, unit.energy + 0.15);
        unit.merged_from = [...(unit.merged_from || []), existingUnit.id];

        // Remove old unit from index
        indexManager.removeEntry(entry.id);
      }
    }
    return unit;
  }
}
```

## Decision Log

| # | Decision | Rationale |
|---|---|---|
| 1 | HybridCompressor.compress() returns HarmonicUnit directly | Avoid extra conversion step |
| 2 | Compressor writes to tier files + index | Single-entry point for all harmonization |
| 3 | MinHash signature size=4, threshold=0.6 | Small memory footprint; matches spec |
| 4 | Merged units remove old index entry | Prevent duplicate results in search |
| 5 | M6 tests all in one file | E2E focus, not unit-by-unit |
