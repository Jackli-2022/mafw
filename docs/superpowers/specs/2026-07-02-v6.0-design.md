# MAFW v6.0 Architecture Design

> **Codename**: Aligned Platform  
> **Design philosophy**: From executor to alignment platform — balancing user preference, cost budget, and historical experience.  
> **Core upgrades**: Checkpoint backtracking, Hybrid compression, Cognitive routing, Cost telemetry, User interaction tools.

### 1.3 Cost Estimator

**New files**: `src/cost/cost-estimator.ts`, `src/cost/types.ts`

Estimate token/cost per tool call using fixed coefficients:

| Tool | Estimated Tokens |
|---|---|
| `file_edit` / `file_write` | 0 |
| `mafw_observe` | 0 |
| `mafw_search_hybrid` | 0 |
| LLM calls | `inputChars / 4` |
| `mafw_review` | `inputChars / 4` |

Cost = `estimatedTokens * 0.003 / 1000` (Sonnet rate; Haiku rate is half).

```typescript
interface CostRecord {
  goalId: string;
  loopNum: number;
  waveNum?: number;
  toolName: string;
  estimatedTokens: number;
  estimatedCost: number;
  timestamp: string;
}
```

**Storage**: New SQLite table

```sql
CREATE TABLE IF NOT EXISTS cost_logs (
  id TEXT PRIMARY KEY,
  goal_id TEXT NOT NULL,
  loop_num INTEGER NOT NULL,
  wave_num INTEGER,
  tool_name TEXT NOT NULL,
  estimated_tokens INTEGER DEFAULT 0,
  estimated_cost REAL DEFAULT 0,
  timestamp TEXT NOT NULL,
  metadata TEXT
);
```

### 2.2 Cognitive Router (Agent-level)

**New file**: `src/cost/cognitive-router.ts`

Config-driven model selection per Agent. No Tool registration needed — decision happens when creating sessions.

```typescript
interface RouterConfig {
  agents: {
    plan: { model: string; priority: 'quality' | 'cost' };
    execute: { model: string; priority: 'quality' | 'cost' };
    review: { model: string; priority: 'quality' | 'cost' };
  };
  budget: {
    total: number;
    perGoal: number;
    threshold: number;   // 0.8 = 80%
  };
}

function selectModel(
  config: RouterConfig,
  agentType: 'plan' | 'execute' | 'review',
  remainingBudget: number,
  totalBudget: number
): { model: string; reason: string } {
  const usage = 1 - (remainingBudget / totalBudget);
  if (usage > config.budget.threshold && agentType === 'execute') {
    return { model: 'haiku', reason: 'budget_threshold' };
  }
  return { model: config.agents[agentType].model, reason: 'default' };
}
```

**Config file**: `.mafw/router.json`

```json
{
  "agents": {
    "plan": { "model": "claude-sonnet-4-20250514", "priority": "quality" },
    "execute": { "model": "claude-sonnet-4-20250514", "priority": "quality" },
    "review": { "model": "claude-haiku-3-5-20241022", "priority": "cost" }
  },
  "budget": { "total": 1000000, "perGoal": 200000, "threshold": 0.8 }
}
```

**Changes**:
- `src/cost/cognitive-router.ts` — new ~50 lines
- `.mafw/router.json` — new ~15 lines
- `src/plugin.ts` — inject router config when creating sessions (+15 lines)

## P3: Productization

**Goal**: User interaction tools, SCORE display, alignment dashboard, intervention timeline.

### 3.1 mafw_ask_user (Non-blocking)

**New file**: `src/tools/run-ask-user.ts`

Tool registration:

```typescript
{
  name: 'mafw_ask_user',
  description: 'Ask user a clarifying question (non-blocking, answer consumed next loop)',
  parameters: {
    question: { type: 'string' },
    options: { type: 'array', optional: true },
    priority: { type: 'string', enum: ['normal', 'high'] }
  }
}
```

**Data flow**:
```
Agent calls mafw_ask_user
 → Plugin writes .opencode/mafw/user-questions/{goalId}-{loop}-{id}.json
 → Plugin POST /api/events { type: 'user.question', data: question }
 → Gateway SSE push to Dashboard
 → Dashboard shows question notification bar
 → User submits answer
 → Dashboard POST /api/user-answers/{questionId}
 → Gateway writes answer file
 → Next Loop/Wave memory injection reads it
```

### 3.3 SCORE Display

**File**: `src/tools/run-review.ts` (modified)

```typescript

  verdict: 'PASS' | 'FAIL';
  score?: number;     // 0-100, display only
```

LLM prompt requests score output. State machine continues using PASS/FAIL for routing. Dashboard displays score as a ring chart on Loop cards.

### 3.4 Alignment Dashboard

Dashboard view with:
- **Goal weight sliders**: Speed/Quality/Cost (0-1, sum to 1)
- **Alignment score**: `1 - Σ|userWeight_i - actualWeight_i| / 2`
- **Cost dimension deviation alert**: if actual cost weight differs from user target by > 0.15
- **Router suggestion**: recommends model switch based on deviation

### 3.5 Intervention Timeline

New Dashboard timeline view showing:
- User correction events (from `mafw_record_feedback`)

- Incremental replanning count per event

## Decision Log

| # | Decision | Rationale |
|---|---|---|
| 1 | Keep Loop/Wave naming, no Spiral rename | ~50 files would change; zero behavioral benefit |
| 2 | SCORE 0-100 is display + record only; state machine stays PASS/FAIL/PARTIAL | Avoids ~15-file state machine refactor; PARTIAL already provides similar branching |
| 3 | Vector Clock dropped; OptimisticSync gets causal context | No concurrent file-write conflict exists in current WaveDependency model |
| 4 | JSON checkpoint + file manifest, no tar.gz | tar.gz has Windows compatibility risk; JSON is sufficient |
| 5 | mafw_ask_user is non-blocking (Dashboard notification) | opencode SDK doesn't support Agent suspend/resume |
| 6 | Cost Telemetry is estimation-based | Plugin cannot intercept opencode child process LLM tokens |
| 7 | Cognitive Router is Agent-level, config-driven | Simpler than Task-level; decoupled from SDK model-switching API |
| 8 | Store cost data in SQLite `cost_logs` table | Existing SQLite storage infrastructure, no new backend |
| 9 | Three-phase delivery (P1→P2→P3) | Each phase independently shippable; P1 is 3-4 days |
| 10 | No modification to inherited v5.0 modules | Search/Graph/Storage/StateLock/Tokens are stable and working |
