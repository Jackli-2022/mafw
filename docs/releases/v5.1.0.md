# v5.1.0 — Orcalore 品牌 + Lead 身份收敛 + Mobile 工作 tab

日期：2026-11-09
类型：**minor release**（无 breaking change）

本版本三条主线：

1. **Orcalore / Lore 品牌**：桌面左上品牌位、聊天流 Lore 标记，移动端整体换装（mint/ink/cream、app identity、深链）。
2. **Lead 身份收敛**：Lead 的名字与角色标记不再被 runtime 自动摘要改写（tab + 聊天区头部）。
3. **Mobile v1 骨架**：3-tab 外壳、工作 tab、Goal 详情、plan approval、从工作 tab 直接建 Goal。

## 桌面

### 品牌

- 左上品牌位：`M` + `MAFW` 退役，改为 **Lore 18px 圆标 + `Orcalore` 字标**；≤900px 只留图标。
- 聊天流 Lore 标记：每个 assistant 回合**开头一次** 16px 圆标，正文让出 **28px 左侧留白**（Claude 式通栏 + 首行 logomark）。
  - 回合以正文开头时对齐第一行（`top: 18px`），以工具卡开头时贴齐回合顶（`top: 4px`）。
  - 回合内工具卡 / 续写不重复；流程卡与审批汇总同步 28px 内边距。
  - 纯 CSS 伪元素，无 `img`/alt/角色语义，`session-ui` 零改动。

### Lead 身份

- Lead tab 保持 `L` 徽标 + 完整 `Lead` 文本：隐藏冗余状态点、标题 `flex: 0 0 auto` + 34px 下限、关闭按钮 16px。
- **名字钉死**：tab 标签（`sessions()`）与 ChatPane 头部（`store.session`）都只认角色名，runtime 的自动标题（如「问候」）不再改写它。
- Lead tab 禁用双击改名，避免「改了又被钉回」。

### 修复

- 右 dock 工作概览：Goal 行被 `ButtonV2 size="small"` 的固定 `height: 24px` 压扁，导致 hover 背景只覆盖 24px、溢出文字压到下一行/下一组；改为内容撑高（`height: auto` + `min-height: 30px`）。
- 会话配置菜单：Thinking 展开 8 档后下半截被 `overflow: hidden` 裁掉；菜单放宽到 `min(480px, calc(100vh - 16px))`、rows 允许滚动、popover 按内容重新锚定。

## Gateway

- `session.setThinkingLevel` 落地：七档（off/minimal/low/medium/high/xhigh/max）映射到当前模型 variants（精确 id/effort 优先、缺档取最近、`off` 优先 `none`/`thinking.disabled`），复用 `POST /session/:id/model`；`thinkingLevelSupported` 随之变 true，桌面菜单可直接选档。variant 目录仍只在适配器内，前端不感知。
- `/api/provider`：带**内联 apiKey**（opencode 配置 `settings.apiKey`）的 provider 也计入 `connected`（此前蓝区 `gateway` 被标为未连接，桌面模型选择器整组隐藏）。
- `GET /api/presence`：attention 条目补 `podId` / `projectId`，托盘与通知可跨项目导航。
- `deploy:local` 同步 `bin/mafw.js`（此前拷贝式部署漏掉 CLI 入口）。

## Runtime / 插件

- `mafw plugin-check <file> --audit`：用插件 `eventMappings` × `runtime-contract.json` 交叉核对，并让 `sampleEvents` 过真执行器。四类结论：翻译不对、缺必需字段、没有输出、接口面不对；`--probe` 真调 10 个只读面。退出码 1 = error。
- claude adapter：`system/init → session.created` 补 `info.id` / `info.directory`，修复会话列表不刷新（审计首跑发现）。
- SDK：输出自包含 `events.schema.json`（98 个事件变体 / 175 `$defs`）。
- 注：`gen:opencode-ref` 参考生成脚本同批引入后**已回滚**，不在本版交付面内。

## Mobile（Orcalore v1，进行中）

- **品牌**：accent 紫 → mint `#4FD388`，ink `#1D1F25` / cream `#FCF8F1`；`applicationId ai.orcalore.mobile`、包名 `orcalore_mobile`、深链 `orcalore://pair`（gateway `pairing.ts` 同步发射 `orcalore://` 链接）。
- **外壳**：3-tab（工作 / 聊天 / 我）。
- **工作 tab**：品牌行、五桶（needs_you / queued / in_progress / result_ready / ended）、「需要你」跨项目条目、active project 记忆、15s 轮询 + 事件驱动局部刷新。
- **Goal 详情**：时间线 / 阶段 / 结果 / 打回；plan approval 卡（`approve` 带 planHash/evalHash，409 `stale_plan` 提示重新拉取）。
- **Pod 协作 client**：`createGoal` / `techLead` / attention 表单。
- **从工作 tab 建 Goal**：FAB → `podLookup`（无 Pod 时 `podEnsure`）→ Goal composer → 成功后进 Goal 详情；错误可区分（网关过旧 / 项目未注册 / 网关未配置）。
- **网络**：WsClientV2 + header auth、SmartReconnect 状态持久化、`ts.net` 与单标签/`.local` 主机的明文判定、诊断面板。
