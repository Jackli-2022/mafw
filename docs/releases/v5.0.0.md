# v5.0.0 — Runtime Experience 全量迁移 + Pod 协作 Goal Loop

日期：2026-11-03
类型：**breaking release**

本版本包含两条主线：

1. Runtime Isolation / Experience Contract 第二批全量收口（破坏性）
2. Pod 协作 Goal Loop：Lead / Tech Lead / Builder / Reviewer

## Breaking changes

### Runtime / HTTP / SSE

- `GET /api/sessions/:id/messages` 只返回 flat `MafwMessage`：`{ data, nextCursor }`。
  `{info, parts}` 历史信封和 `?format=flat` 迁移参数已删除。
- `message.updated` 只携带 `properties.message`；不再向客户端发送
  `properties.info`。历史 `event_log` 会在启动时幂等迁移，旧 `message.error`
  wire shape（`{name,data:{message}}`）同步转为 `{kind,message}`。
- 删除：
  - `GET /command`
  - `GET /skill`
  - `GET /api/skill/content`
  - `GET|PATCH /api/opencode-config`
- SDK 删除：
  - `session.history`
  - `shells`
  - `requestRuntime`
  - legacy `command` / `skill`
  - `opencodeConfig` 别名
- preload 删除通用 `window.api.mafw.invoke(namespace, method, ...)`。只保留 typed namespaces。

### Runtime plugin / capability

- gateway 业务核心只接受 canonical facade/access；裸 runtime capabilities、runtime 名分支和
  原生 SDK 类型不再作为业务门。
- `POST /api/session/:id/background`、`/api/background/jobs*`、`/api/terminal/*` 成为中性公共面。
- terminal 统一使用 `mafw-terminal/1`；原生 PTY 帧、`/api/pty` 和 `x-opencode-ticket` 仅存在于 adapter。
- worktree 归属改为 gateway git + `session.create({directory})`，不再使用 `worktreeApi` 限制 pi/claude。
- Experience 使用 `supported` / `enabled` 分离；`/api/experience/actions` 当前版本 `2026.11.1`。

### Clients

- desktop / TUI / mobile 必须与本版本 gateway 同步升级；旧客户端不能连接新 gateway。
- session-ui 不再依赖 `@opencode-ai/sdk`。
- mobile 历史读取与 SSE 已迁移到 flat DTO / `mafw_event` canonical 事件。

## Pod 协作 Goal Loop

新增 Lead / Tech Lead / Builder / Reviewer 协作循环：

- 直接 Goal → Tech Lead 讨论 → 方向裁定（按需）→ plan + Goal Eval 人工批准 →
  实施 → 独立 rubric review → 结果 → 用户打回 → revision 2。
- revision append-only，产物按 revision 隔离；旧 revision 证据不重写。
- Probe / Spike、上下文 manifest、计划 hash 批准、逐任务验收和 Goal Eval 条件校验。
- 迁移兼容：旧三成员 Pod 自动补 Tech Lead；legacy goal bootstrap 到 revision 1。

详见 `AGENTS.md` §5.25 与 spec/plan 文档。

## 升级前检查

1. 备份 `~/.mafw/memory/gateway.db` 和 `~/.mafw/logs/`。
2. 确认 desktop/TUI/mobile 与 gateway 同版本升级。
3. 旧客户端依赖的 `/command`、`/skill`、`session.history`、`{info,parts}` 已删除。
4. event_log 迁移会自动备份到
   `~/.mafw/logs/event-log-message-migration-<timestamp>.jsonl`；备份失败时迁移中止。

## 回滚

- 代码回滚到 v4.42.3 tag 前需同时回滚 event_log 迁移：
  使用迁移备份 JSONL 按 `seq` 恢复 envelope。
- 回滚后旧客户端可继续连接旧 gateway；新客户端与旧 gateway 不兼容。
