## 交付内容

### 1. 能力契约

`memory/skill-contract.ts`：

- 从 procedural memory 解析 `triggers / negative_triggers / inputs / outputs / steps / tools / permissions / success_criteria / failure_handling / scope`（支持中英文标题与 inline 字段）。
- 回退：triggers 取非命名空间 cue anchors；negative triggers 取 `not:` / `negative:` 锚点；scope 取 `session:<source_session_id>`。
- 校验：至少 1 个 trigger、至少 2 个稳定步骤、至少 1 个 scope；不满足不进入 staging。
- `renderSkillMd` 输出完整 frontmatter（version/status/source ids + 契约字段）和分节正文；缺省字段显式标“待补充（人审）”。

### 2. 能力注册表与安装版本

- `gateway.db` 新表 `skill_registry(name PK, version, status, source_memory_ids, source_trace_ids, installed_at, updated_at, deopt_reason)`。
- `recordSkillInstall`：同名安装默认 version+1，可显式指定版本；状态 `active`。
- `installSkillDraft` 接受 `version/sourceMemoryIds/sourceTraceIds`，安装成功后写入注册表；注册表失败不影响已复制的 skill。
- triage 草稿新增 `version/sourceMemoryIds/sourceTraceIds`，人审确认仍是唯一安装入口。

### 3. Deopt

- `deoptSkill(name, reason)`：把 `<skillsDir>/<name>` 原子移动到 `<skillsDir>/.disabled/<name>-<timestamp>`，把注册表置 `paused` 并记录原因。
- 下一次 runtime 发现/激活边界生效；不承诺撤回已经注入运行中会话的指令。
- `POST /api/skills/:name/deopt`（operationId `skills.deopt`, internal）是唯一 deopt 入口；名称非法/不存在返回 404。
- `installedSkillCount` 忽略 `.disabled`，避免 deopt 反而触发列表膨胀闸门。
