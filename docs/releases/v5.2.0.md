# v5.2.0 — 工作台页面化 + 工具卡重构 + 记忆回执 + Relay

- **日期**：2026-11-21
- **类型**：minor release（无已知 breaking change）
- **范围**：`v5.1.0`（2026-11-09）→ `v5.2.0`，1,774 commits
- **产品版本**：`5.2.0`（root / desktop / SDK / session-ui / ui / tui / runtime-kit / test-shim 同步）

本版本的四条主线：

1. **主区只留 chat**，Approvals / Triage / Automations / MCP / Config / Memory 全部进入右侧工作台的常驻 page tab。
2. **工具卡与时间线重构**：过程抽屉、默认折叠、rich presenter、diff / read / CodeMode 统一卡片。
3. **记忆回执与 recall 质量**：每轮回答附带记忆回执，P0/P1 质量基线与 shadow pilot 落地。
4. **Relay / Mobile**：新增 relay 包（SNI/TLS、房间、配额、SQLite），移动端走 pinned relay transport。

## 桌面

### 主区 chat-only + 右侧工作台页面

- 新增通用 page subject：`subjectKey = page:<id>`，持久化 scene tab `scene:page:<id>`；页面作为右 dock 的
  focus page 打开，只能通过 FrameBar 返回 / tab 关闭退出，不能替换主区聊天。
- 六个页面迁入右侧工作台：**Approvals / Triage / Automations / MCP / Config / Memory**；Config 支持
  `openConfigPage(section)` 在已挂载时切段。窄栏使用 compact 布局，不出现横向溢出。
- 关闭 tab 时同步剪掉该 page 的 focus；已关闭 / 被 MAX_TABS 裁剪的 scene tab 由 `ensureSceneTabFor` 重建。

### Chat

- **滚动条始终贴底**：会话切换重新锚定；`MutationObserver` + `ResizeObserver` + 32ms timer 兜底，
  异步排版（markdown / 图片 / 工具卡 / 收件箱）长高后仍吸附底部；用户向上滚仍释放。
- **输入栏底部信息条**：时间 / 城市在最左，会话脉搏居中（`缓存命中 % · tokens · tok/s · 回合`），
  右侧留空槽；窄栏 <430px 自动收起左侧时间 chip。
- 上下文 ghost row + popover（时间 / 渠道 / 城市 / 语言），城市输入不再溢出 popover。
- Lead 外部事件收件箱过滤系统 `internal` source；`cron` 保留 Cron 标签。
- 修复用户消息开头多余空行、thinking 行与工具卡几何对齐。

### 工具卡 / 时间线

- 回合切换为 **process timeline**：thinking + 全部工具折叠进同一条过程抽屉，默认折叠、可展开。
- 无损 turn transcript grouping；工具卡默认折叠，rich presenter 覆盖 diff / read / CodeMode / MAFW family。
- thinking 时长按 reasoning 时间戳显示；删除 composer 上方多余的 generating strip。

### 文档与记忆面

- 文档 tab 持久化、文件树右键/滚轮切换、Ctrl+P picker palette。
- 记忆回执挂在回合内（quiet closing line），点击打开 peek；memory receipt 链接不再把页面挤出右 dock。

## Gateway / Runtime

- **client channel**：gateway 在 prompt 路由写入 `clientChannel`，desktop / TUI / mobile 各自声明渠道，
  mobile 注入上下文剥离。
- E10 请求/响应契约、route catalog、SDK contract 对齐；gateway kernel D2/D3 事件分发与 boot kernel 合入。
- Pod / Goal：已归档 Goal 的 hide / unhide / purge / cleanup，standing goals，Lead / Tech Lead P0–P2，
  Goal 用户视图与 attention 投影。
- 插件信任面：plugin check / audit、runtime contract 交叉核对、SDK 自包含事件 schema。

## 记忆

- **memory receipts**：结构化 receipt builder、turn anchor、持久化与 SDK endpoint；回答后生成，不回流 T1。
- **recall 质量**：P0 foreground 隔离 + scheduler metrics；P1 session-shaped quality baseline 与 frozen
  shadow pilot；T1 provenance / activation / retrieval 分层；decay / consolidate / reflect / dream 管线保持批量写。
- 记忆页进入右 dock；便签 / pinned / supersede 语义不变。

## Relay / Mobile

- 新增 `packages/relay`：frame mux、room registry、SNI parser / TLS router、host control hub、配额、
  SQLite 房间声明、Docker 部署。
- Mobile：relay tunnel client、pinned relay transport、pairing link 带 relay endpoint、relay identity store、
  M3 / M4 验收。
