## 交付内容

### 1. Reflection 小步分批

- `config.recall.reflectionBatchSize` 默认 `10`，`ReflectionOptions.reflectionBatchSize` 可覆盖（最小 1）。
- `reflectSession` 将 episodes 按批次处理，每批独立走 question → evidence → replay → distill → write → cursor。
- 某批 worker 失败只保留该批未反思；后续批次继续处理。
- `ReflectionResult` 聚合 `reviewed/distilled/replayedTraces/replayChars`，`sessions` 归一为 1。

### 2. 重复写入强化

`routeAndWrite` 的 `skip` 分支：

- 当 incoming write 带 `source_trace_ids` 时，读取目标、并集 provenance、写回目标；
- 能量 `min(1, target.energy + 0.02)`，有界强化；
- 返回 `{ action:'skip', reinforced:true }`；
- 无 provenance 的重复写入保持旧行为（纯 no-op，不写盘）。

### 3. Raw-T1-aware 再巩固

- `ReconsolidateDeps.t1Replay` 注入 4A collector 依赖。
- 每个有 newer related 的候选，额外收集：
  - 该 memory 的精确 `source_trace_ids`（exact）
  - 高 activation trace
  - 以 `primary_abstraction` 为 query 的 T1 检索命中
- 证据块上限 3000 字符，追加到 keep/rewrite prompt；`SYSTEM` 明确它是 inert 验证证据。
- prompt 成功后 `markT1Replayed(usedTraceIds)`，`ReconsolidateResult.replayed` 记录数量；worker 失败不标记。
- `keep` 仍不写盘；只有既有 prediction-error gate（rewrite）产生新版本 + soft supersede。
