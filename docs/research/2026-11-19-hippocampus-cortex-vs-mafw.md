# 海马体 / 皮层 与我们做的：机制对照

> 2026-11-19。问题：我们做的“稀疏分解”海马体真的在做吗？我们的“皮层”功能与真实皮层一致吗？
> 结论先说：**海马体做的是稀疏编码/模式分离，不是把 embedding 分解成 12 个命名概念；
> 我们的 harmonic 层是外部语义知识库，不是慢学习的分布式皮层。** 两层是功能类比，不是机制复刻。

## 1. 海马体实际做什么

- **DG（齿状回）**：输入来自内嗅皮层，颗粒细胞数量远大于输入通道，形成**扩张 + 稀疏**编码；
  活跃比例很低（啮齿类约 1–5%），相似经历被映射到**低重叠**的细胞集合——这就是 pattern separation。
  它是稀疏**编码**，不是“把向量分解成一组可命名的概念”。
- **CA3**：递归侧支构成自联想网络，部分线索补全整体（pattern completion）。
- **CA1**：比较 EC 输入与 CA3 补全结果（comparator），失配时触发新编码/更新。
- **Engram 分配**：稀疏、竞争性；兴奋性/CREB 等决定哪些神经元进入 engram。
- 关键点：稀疏性是**高维、低激活率、去相关**；不是“12 个标签里选 2 个”。

## 2. 我们实际做什么

- 12 个手工 anchor（`error:*`、`action:*`、`actor:*`、`concept:*`），每个 anchor 一条文本；
- turn 文本 embedding 与 anchor 求 cosine，减去 per-anchor baseline 与文本均值，取 top2；
- 写入 `t1_sparse_terms(kind='semantic')`，检索时作为 `sem:` 词项参与 RRF。

实测（live DB，4,545 turns）：

| 指标 | 值 |
|---|---:|
| 有原子的 turn | 3,323（73%） |
| 恰好 2 个原子 | 3,208（70.6%） |
| 1 个原子 | 115（2.5%） |
| 0 个原子 | 1,222（27%） |
| 相邻同 session 回合的原子 Jaccard | **0.458** |
| 随机跨 session 回合的 Jaccard | 0.212 |
| `sem:error:connection_reset` 覆盖 | 1,865 turns（41%） |

读法：
- 密度固定 2/12 ≈ 17%，不是 DG 式的低激活率；70% 的 turn 都拿满 2 个，说明“稀疏”由 topK 决定，不是由内容决定。
- 相邻回合共享近一半原子，随机也有 0.21——**去相关能力很弱**；相似经历没有被映射到低重叠码。
- 一个 anchor 覆盖 41% 的 turn（hub），baseline 校正压低了分数，但没有改变“谁都能命中它”的事实。

所以：我们的“稀疏分解”更准确的叫法是**12 维可解释概念打标器 + 各向异性校正**，不是海马体式稀疏编码。

## 3. 皮层实际做什么

- 新皮层是**分布式、重叠、慢学习**的生成模型：语义知识分布在大量突触上，不是一条条可编辑的文本；
- 通过睡眠回放从海马抽取统计结构（CLS），逐步脱离海马；
- 记忆是**重构**的（线索 + 图式 + 预测），不是按 id 查找；
- 图式一致时巩固加速，不一致时需要更多海马参与。

## 4. 我们的 harmonic 层实际做什么

- 离散文本 unit（OKF 文件 + index），LLM 写/摘要，energy 衰减，soft supersede；
- 检索是 BM25 / 向量 / 图扩展 / RRF，不是重构；
- consolidation 是 LLM 判官 + 去重/合并，不是慢速权重更新；
- 有 `schemaClusters`，但没有用于写入/巩固调度。

功能上确实覆盖了“长期语义存储 + 抽象 + 遗忘/取代”，但机制上：
- 没有分布式表征（每条记忆是原子文本）；
- 没有慢学习（写入是一次 LLM 调用）；
- 没有预测/重构（检索是查找 + 图扩展）。

所以：把 harmonic 叫“皮层”是**功能类比**（长期知识库），不是机制等价。

## 5. 对照表

| 维度 | 海马体 | 我们的 T1 atoms | 皮层 | 我们的 harmonic |
|---|---|---|---|---|
| 表征 | 高维稀疏细胞集合 | 12 维命名概念 | 分布式重叠权重 | 离散文本 unit |
| 稀疏性 | 1–5% 活跃 | 固定 top2（17%） | 不稀疏 | 不适用 |
| 分离/完成 | DG 分离 / CA3 完成 | 弱分离（Jaccard 0.46） | 重构 + 图式 | 1-hop 图扩展 |
| 学习 | 快速、单次 | 无学习（手工 anchor） | 慢速、统计 | LLM 一次写入 |
| 比较器 | CA1 | mismatch 分数（shadow） | 预测误差 | 无 |

## 6. 如果要在机制上更接近，应该做什么

1. **真正的稀疏码**（替代/补充 12 anchor）：
   - 随机扩张 + k-WTA（无需训练，先把 embedding 投到 4–8k 维，取 top 0.5–2%）；
   - 或训练一个 k-WTA 稀疏自编码器（8k 特征，top 16）；
   - 或 SPLADE 式词表稀疏。
   评价标准：相邻回合 Jaccard 显著下降、随机保持低、recall@3 不降。
2. **Engram 式分配**：哈希分桶 + 竞争性写入，避免 hub anchor。
3. **皮层侧**：如果真要“慢学习”，需要分布式关联权重（embedding + 图 + 小型学习模型），而不是更多文本 unit；成本高，先证明检索收益。
4. **命名诚实**：在文档/代码注释里把 `sem:` 叫“concept tags”，不要叫 DG/CA3；把 harmonic 叫“long-term semantic store”，不要叫 cortex，除非机制对齐。

## 7. 建议的最小实验

用现有 turn embedding 做一次**随机扩张 + k-WTA**（不训练、不调 LLM）：

- 维度 4096，top 16（0.4%）；
- 在 200 个 turn 上比较：相邻 Jaccard、随机 Jaccard、与 12-anchor 方案的检索 recall@3；
- 如果相邻 Jaccard 从 0.46 降到 <0.1 且 recall 不降，说明“真稀疏码”值得替换；
- 否则保留概念打标器，但改掉“稀疏分解/海马体”的说法。
