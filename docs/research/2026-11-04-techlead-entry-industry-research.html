业界样本 · 一

Devin：每一步都应一键可达

“With Devin 2.2, we rebuilt every screen of the UI around a simple idea: each step of the dev lifecycle should always be one click away.” — Cognition, 2026-02 · Devin 2.2 发布

Progress Tab

会话内任务列表做成 live drawer；点击任务 → Activity 流过滤到该任务的工作。任务为中心导航，2026-10 上线。

Spaces（Windsurf 2.0）

按任务聚合 agent 会话 / PR / 文件 / 上下文。“切换 Space 就是切换任务”，每个任务里有一队 agent 在干活。

Agent Command Center

全部 local + cloud agent 按状态的 Kanban：“工程师的工作从写码变成指挥——要看到谁在做什么、什么被阻塞、什么待审。”

→ 对 MAFW 的映射：Goal 就是任务对象。讨论是 Goal 生命周期的一步，入口应挂在 Goal 上，一步可达。

收束

一句话结论

Tech Lead 需要按 Goal 组织的持久入口，而不是只在 discussing 一瞬出现的邀请。业界四种模式里，任务为中心（Devin）+ Goal 感知 roster（Claude Code）正对 MAFW 的形态；你给的「chat 页拉 Tech Lead、点击进讨论页」就是入口 A，配上 Goal 详情常驻按钮（入口 B），gateway 零改动即可落地。
