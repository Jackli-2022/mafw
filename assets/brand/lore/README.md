# Lore brand assets

Lore is Orcalore's memory pearl and the Lead's visual identity. This directory
holds the normalized, ASCII-named copy of the user-generated Lore icon pack.

## Provenance

- Generated by the user; the original `Lore平台图标资产/` input pack is **not**
  committed.
- The platform exports are treated as read-only inputs for the later Orcalore
  rename. This plan does not wire them to production app icons yet.

## Source masters

| File | Meaning |
|---|---|
| `source/lore-pearl-1024.png` | Transparent pearl with the thread/tag signature |
| `source/lore-pearl-simplified-1024.png` | Simplified pearl (eyes + highlight, no thread/tag) — used for avatars |
| `source/lore-monochrome-1024.png` | Monochrome silhouette for template / monochrome themes |

## Avatar pack

`avatar/` is the user-generated 15-size pack (16, 20, 24, 28, 32, 40, 48, 64,
80, 96, 128, 160, 256, 512, 1024), in two variants:

- `avatar/circle/` — ink circular background + pearl; self-contained badge.
- `avatar/transparent/` — transparent pearl; for custom backgrounds.

16/20/24 use the simplified base (no thread/tag); 28+ include the thread/tag.
UI consumes 16px circle (SessionStrip Lead tab) and 32px circle
(ProjectResources Lead row); 64px circle is kept for future surfaces.

## Platform pack

`platform/` is a read-only export pack (Windows ICO/PNG, macOS ICNS, Linux
hicolor, Android adaptive/monochrome, previews, original asset manifest).
It is consumed by the later Orcalore rename plan; do not edit it in place.

## Generated assets

`export/` is generated by `packages/desktop/scripts/build_lore_assets.py`
(Task 2): copies the avatar pack (`export/avatar/circle|transparent`) and
derives tray templates and favicon. The UI copies live in
`packages/desktop/src/renderer/mafw/assets/lore/`.

## Gaps

- No SVG or Android Vector Drawable source yet.
- No iOS / Windows Store / social banner assets.
- No character sheet, expressions, accessories, doodles, or desktop pet in this
  pack; those are a later character-system task.
